# Мой ТВ — лаунчер для Android TV (Android 7.0+)

## Как получить APK
1. Загрузите все файлы этого проекта в репозиторий GitHub (папка `.github` обязательна).
2. Откройте вкладку Actions, запустите «Build APK» (Run workflow) или просто сделайте commit.
3. Когда сборка станет зелёной, откройте её и скачайте архив `tv-launcher-apk`, внутри `app-debug.apk`.
4. Скопируйте APK на флешку и установите на телевизоре через «Файлы».

## Как сделать главным экраном
Нажмите кнопку Home. Телевизор предложит выбрать лаунчер, выберите «Мой ТВ» и «Всегда».
Если вопроса нет: Настройки → Приложения → Приложения по умолчанию → Главный экран.

## Плитки
- Телевизор, YouTube, HDMI, Wi-Fi, Настройки: запускают стандартное действие.
- HDMI показывает список входов, которые отдаёт прошивка.
- Удерживайте OK на плитке, чтобы назначить ей любое установленное приложение (например, SmartTube или приложение телевизора).
- Все приложения: сетка со всеми установленными приложениями.

## Что менять
- Название вверху: `MainActivity.kt`, строка `ui.text("МОЙ ТВ", ...)`.
- Фон: заменить `app/src/main/res/drawable-nodpi/bg.jpg` (16:9, лучше 1600×900).
